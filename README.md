# 🏨 Hospitality Analysis - Power BI Dashboard | Atliq Hotels

### 📊 Project Overview
End-to-end analysis of Atliq Hotel Chain (7 properties, 135K+ bookings across India). Built a Power BI dashboard to track KPIs like Revenue, Occupancy, ADR, RevPAR and identify revenue leakage.

### 📸 Dashboard Preview
![Dashboard](dashboard.png)

### 📂 Dataset
- `dim_hotels.csv` - Hotel details (7 properties)
- `dim_rooms.csv` - Room categories
- `fact_bookings.csv` - 135K detailed bookings data
- `fact_aggregated_bookings.csv` - Aggregated metrics

### 🔑 Key KPIs
- **Total Revenue Generated:** ₹2,008M | **Realized:** ₹1,709M
- **Total Bookings:** 135K
- **Occupancy %:** 57.87%
- **ADR (Avg Daily Rate):** ₹18.10K
- **RevPAR:** ₹7.35K
- **Revenue Loss:** ₹299M (14.9%)

### 💡 Key Insights
1.  **Best Performing:** Atliq Blu - Highest Occupancy 62.02%
2.  **Low Performing:** Atliq Seasons - Lowest Occupancy 44.62%
3.  **Major Issue:** 25% Cancellation + 5% No-Show = Huge Revenue Loss
4.  **Booking Trend:** 64K bookings are for 1-day stay only
5.  **Weekend Demand:** 73.58% bookings on weekends
6.  **Pricing Gap:** Atliq City has highest ADR ₹24K but low occupancy

### 📈 Business Recommendations
- Implement strict cancellation policy + advance payment
- Launch 2D/1N packages to increase stay duration
- Dynamic pricing on weekends
- Improve performance of Atliq Seasons property
